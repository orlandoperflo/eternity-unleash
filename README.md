# Eternity

Eternity is a premium first-touch MVP for compiling raw company information into operational intelligence architecture.

## Experience

The MVP includes:

- cinematic landing page for executive buyers
- secure-feeling upload and paste intake
- orchestration and analysis state
- generated operating map
- agent ecosystem cards with permissions and KPIs
- workflow compiler visualization
- executive summary and priority matrix

## Stack

- Next.js App Router
- React
- Tailwind CSS
- Framer Motion
- TypeScript

## Development

```bash
npm install
npm run dev
```

## Production

The app is designed for Vercel serverless deployment with the standard Next.js build pipeline.

```bash
npm run build
npm run start
```
